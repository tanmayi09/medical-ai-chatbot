# Medical AI Chatbot

A Flask-based medical AI chatbot that provides general health-related information through a simple web interface.

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Pytest
- Gunicorn
- Git & GitHub
- GitHub Actions
- Render
